# Security Policy

## Supported Version

Security fixes are applied to the current `main` branch and latest GitHub release.

## Reporting

Please use GitHub's private vulnerability reporting for this repository. Include the affected app or package, reproduction steps, impact, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability.

The sites do not require user accounts or store payment information. Reports about dependency vulnerabilities, unsafe external links, exposed secrets, deployment configuration, and cross-site content injection are still in scope.
